# AI 顧客服務與銷售教練 Service & Sales Coach

將產品知識、顧客情境、服務流程與銷售技巧整合成互動式模擬訓練，讓員工或銷售者練習個人化服務。
可安裝成手機／電腦 APP（PWA），離線也能練；所有練習紀錄只存在使用者自己的裝置，不上傳任何伺服器。

適用：教育訓練、TM、門市、銷售新人、客服。

## 功能

| 分頁 | 內容 |
|---|---|
| 🎯 練習 | 11 個虛構顧客情境（門市／TM 電話／LINE／到府直銷／客服 × 8 種技巧），每個 4 回合；可選 A/B/C 或「自己說」（打字、🎤 語音）；顧客心情即時變化；教練點評＋參考說法；依角色與弱項推薦下一題 |
| ⚡ 快問快答 | 12 種常見異議（價格、猶豫、決策者、競品、敏感肌、效果…）隨機出題，評分＋教練示範 |
| 🤖 AI 自由對練 | 產生提示詞貼到 ChatGPT／Gemini／Claude，AI 扮演顧客並同步當教練（只含虛構情境） |
| 📚 知識 | 商品 FAB 卡、常見問題、搭配推薦、5 題小測驗；可新增公司實際商品 |
| 🧭 流程 | 服務六步驟「迎・探・薦・解・成・續」、異議處理 LSCPA、各通路提醒、合規用語對照 |
| 📈 成長 | 五力雷達、分數趨勢、9 個徽章、各情境最佳成績、分享成長報告、匯出 CSV |
| ⚙️ 更多 | 角色、自動朗讀顧客台詞、大字、深淺色、安裝、講師帶領指南、備份還原 |

## 評分方式（五力）

💗 同理傾聽、🔍 需求探詢、📘 產品專業、💎 價值說明、🤝 推進成交。

- 選項作答：每個選項有預先設計的面向分數；每回合滿分以「最佳回答」示範到的面向為準。
- 自由作答：依同理用語、提問、商品關鍵字、價值換算、下一步行動等規則計分，並加上各回合專屬關鍵字。
- 合規：出現「保證、治療、不會過敏、凍齡…」等用語會標記 ⚠️ 並扣 10 分；前面有否定詞（「不能治療」「不敢保證」）不算。
- 顧客心情：最佳 +15、普通 +3、不佳 −15、違規再 −15；降到 5 以下顧客提早離開。

## 開發

```bash
node scripts/serve.js 5250        # 本機預覽 http://localhost:5250
node scripts/make-icons.js        # 重新產生圖示
node scripts/stamp-sw.js          # 改完任何檔案、commit 前執行，讓已安裝的 APP 拿到新版
```

截圖：`?demo=home`、`?demo=play`、`?demo=result`、`?demo=progress`（使用示範資料，不寫入 localStorage）。
localStorage key 與 Service Worker 快取都以 `ssc-` 開頭，可與同網域其他 App 共存。
